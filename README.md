# Visión general

**CardiaI VR Experience** es una aplicación de realidad virtual diseñada para enseñar a estudiantes universitarios a usar un electrocardiógrafo portátil (CAI-100) que detecta arritmias mediante inteligencia artificial.

La experiencia aborda una brecha real: muchas personas evitan hacerse exámenes cardíacos por miedo, desinformación o ansiedad. A través de un entorno calmado, un robot guía y actividades lúdicas, el usuario aprende:

- Las partes del dispositivo y cómo usarlo
- Cómo funciona eléctricamente el corazón
- Qué significan los 4 posibles diagnósticos
- A realizar una medición correcta

**Estado actual:** En desarrollo activo - Prototipo funcional
